데이터: iShares와 Invesco가 공개한 ETF 보유 내역(전 거래일 기준)을 GitHub Actions가 매일 수집해 etf-rebalancing-tracker 저장소에 커밋합니다. 이 페이지는 저장소의 reports/summary.json, history.json, briefing/latest.md 사본을 담아 매일 다시 발행되며, GitHub 커넥터가 연결된 계정에서는 열릴 때 저장소를 직접 읽습니다.
상한 점검과 강제 매매표의 비중은 주식만으로 재정규화한 ETF 비중, 분해표의 비중은 현금과 파생상품을 포함한 펀드 비중이며 둘 다 지수 비중의 근사치입니다. 추정 금액은 비중 변화에 순자산을 곱한 값입니다. 규칙 출처는 저장소의 docs/methodology.md입니다.
